Practice Questions

Q1: Which US Department of Defense research network became a central packet-switching predecessor of the Internet?
  1. ARPANET ←
  2. NSFNET
  3. CYCLADES
  4. NPL network
ARPANET connected research sites and advanced packet networking; it was infrastructure history, not a short-range radio standard.
Q2: What happened on ARPANET in 1983 that became an Internet-history landmark?
  1. It adopted TCP/IP ←
  2. It adopted the OSI protocol suite
  3. It became the first commercial Internet service provider
  4. It was replaced by the World Wide Web
ARPANET's transition to TCP/IP on 1 January 1983 helped establish a common protocol suite for interconnected networks.
Q3: Which trio was introduced together in Tim Berners-Lee's Web architecture at CERN?
  1. URL, HTTP, HTML ←
  2. TCP, IP, SMTP
  3. DNS, FTP, Telnet
  4. XML, CSS, JavaScript
The Web combined resource addresses through URLs, transfer through HTTP, and hypertext documents written in HTML.
Q4: Typing a domain name succeeds even though routers use numeric addresses. Which service bridges the two?
  1. DNS ←
  2. DHCP
  3. ARP
  4. NAT
DNS resolves human-readable domain names to IP addresses that network software can route.
Q5: Which feature most clearly separates 5G from Bluetooth?
  1. 5G is a cellular wide-area generation ←
  2. 5G and Bluetooth use the same network range and infrastructure
  3. 5G is designed only for direct peripheral pairing
  4. 5G works without a cellular operator’s radio-access network
5G uses operator cellular infrastructure for broad coverage and capacity; Bluetooth is intended for short-range personal-area links.
Q6: A wireless keyboard connects directly to a laptop a metre away. Which standard is the likely choice?
  1. Wi-Fi Direct
  2. NFC
  3. Bluetooth ←
  4. Zigbee
Bluetooth is optimised for low-power, short-range exchange between nearby personal devices and peripherals.
Q7: Which chronology is correct?
  1. Web invention, ARPANET creation, TCP/IP adoption
  2. ARPANET creation, TCP/IP adoption, Web invention ←
  3. TCP/IP adoption, Web invention, ARPANET creation
  4. TCP/IP adoption, ARPANET creation, Web invention
ARPANET began in the late 1960s, adopted TCP/IP in 1983, and the Web was proposed at CERN in 1989.
Q8: DNS has returned an IP address. What protocol family then carries data across the Internet?
  1. TCP/IP ←
  2. IPX/SPX
  3. AppleTalk
  4. OSI protocol suite
Name resolution supplies the address; TCP/IP provides packet addressing and transport across interconnected networks.
Q9: Which statement avoids a common misconception?
  1. The Web and Internet are exact synonyms
  2. The Web is a service that runs over Internet infrastructure ←
  3. ARPANET was a web browser
  4. DNS is a replacement for HTTP
The Internet is the network system; the Web is one application layer using that network, alongside email and other services.
Q10: Match the wireless technology to its normal use.
  1. Bluetooth — nationwide cellular coverage
  2. 5G — nearby mouse pairing only
  3. Bluetooth — nearby device exchange ←
  4. DNS — radio access network
Bluetooth handles personal-area connections such as headsets and keyboards, while 5G supplies cellular access over much larger areas.
