Practice Questions

Q1: Which software layer schedules processes, manages memory, and mediates access to hardware?
  1. Compiler
  2. Operating system ←
  3. Database management system
  4. Hypervisor
Resource management and common application services are operating-system responsibilities, distinct from translating code or querying data.
Q2: Which statement carefully distinguishes Linux from a complete operating system?
  1. Linux is a database query language
  2. Linux is the open-source kernel used in many operating systems ←
  3. Linux is a Python compiler only
  4. Linux is a relational table format
Linus Torvalds released the Linux kernel in 1991; distributions combine that kernel with utilities, libraries, and applications.
Q3: A team wants source code translated into a machine-executable form before deployment. Which tool is central?
  1. Interpreter
  2. Compiler ←
  3. Debugger
  4. Package manager
A compiler translates a high-level program into machine code, bytecode, or another target representation used for execution.
Q4: Which creator-and-year pair belongs to Python?
  1. Dennis Ritchie — 1972
  2. James Gosling — 1995
  3. Guido van Rossum — 1991 ←
  4. Linus Torvalds — 1991
Guido van Rossum created Python and first released it in 1991; Torvalds's 1991 release was the Linux kernel.
Q5: A user needs all customer rows whose balance exceeds a threshold. Which language is designed to express that query?
  1. SQL ←
  2. XPath
  3. GraphQL
  4. SPARQL
SQL is the standard declarative language for selecting and managing table data in relational database systems.
Q6: What lets rows in separate relational tables be associated?
  1. Indexes
  2. Keys ←
  3. Views
  4. Transaction logs
Primary and foreign keys identify records and express relationships across tables without placing all data in one table.
Q7: Which match is wrong?
  1. Operating system — hardware resource management
  2. Compiler — source translation
  3. SQL — relational queries
  4. Linux — spreadsheet file format ←
Linux is an open-source kernel, not a spreadsheet format; the other three pairings describe their normal roles.
Q8: A Python service must retrieve records from a relational database. What is the sensible division of labour?
  1. Python handles application logic; SQL expresses the database query ←
  2. SQL replaces the operating system
  3. Linux stores every row as a key
  4. The compiler becomes the database
Application code can call a database driver and submit SQL while Python controls validation, workflow, and response handling.
Q9: Which comparison is accurate?
  1. SQL and Python are both operating-system kernels
  2. SQL specialises in relational data; Python is general purpose ←
  3. Python can only define database tables
  4. SQL was created by Linus Torvalds
SQL focuses on defining and querying structured relational data, whereas Python supports a much wider range of programming tasks.
Q10: A designer stores customers once and links orders to them by customer ID. Which model is being used?
  1. Relational database ←
  2. Document database
  3. Graph database
  4. Hierarchical database
Separate customer and order tables linked by a key are a classic application of the relational model.
