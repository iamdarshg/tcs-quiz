Practice Questions

Q1: Which component fetches and executes a computer program's instructions?
  1. RAM
  2. CPU ←
  3. Solid-state drive
  4. Graphics processing unit
The central processing unit performs instruction execution and coordinates core operations, using memory and other components for support.
Q2: Why is silicon useful in electronic chips?
  1. Its conductivity can be controlled ←
  2. It is always a perfect insulator
  3. It stores data without circuits
  4. It is a quantum algorithm
A semiconductor's controllable conductivity allows engineers to form switching devices such as transistors on silicon.
Q3: What was the key integration achieved by an integrated circuit?
  1. Many electronic components fabricated on one chip ←
  2. One transistor placed in each package
  3. Vacuum tubes wired on a chassis
  4. Separate components connected across a circuit board
Integrated circuits replace assemblies of separately wired components with patterned devices and connections on a compact semiconductor substrate.
Q4: Which property distinguishes ordinary RAM from permanent storage?
  1. It is volatile working memory ←
  2. It retains data without electrical power
  3. It is intended for archival storage
  4. It normally stores read-only firmware
RAM quickly holds active code and data but normally loses its contents when electrical power is removed.
Q5: The letters RISC expand to what?
  1. Rapid Integrated Semiconductor Circuit
  2. Reduced Instruction Set Computing ←
  3. Random Internet Storage Core
  4. Relational Instruction Service Code
Reduced Instruction Set Computing favours a comparatively small collection of simple processor instructions.
Q6: What information unit does a quantum computer manipulate?
  1. Bit
  2. Qubit ←
  3. Byte
  4. Machine word
A qubit is a controlled quantum state; computation uses effects such as superposition and interference rather than ordinary bits alone.
Q7: Which pairing correctly separates roles?
  1. CPU stores files permanently; RAM decodes every instruction
  2. CPU executes instructions; RAM holds active data ←
  3. CPU supplies long-term archives; RAM performs arithmetic
  4. CPU is volatile storage; RAM is the instruction-set design
The processor carries out operations and RAM supplies temporary working contents, so neither substitutes for the other.
Q8: A modern processor contains billions of transistors on a small die. Which two concepts does that illustrate?
  1. Integrated circuit and semiconductor fabrication ←
  2. Discrete-transistor assembly and vacuum-tube logic
  3. Magnetic-core memory and punched-card input
  4. Quantum gates and superconducting qubits
The processor is an integrated circuit, and its transistors are fabricated by controlling semiconductor material.
Q9: Which claim about RISC is a misconception?
  1. It describes an instruction-set approach
  2. It often uses simple instructions
  3. It is a type of volatile memory ←
  4. A CPU can implement it
RISC concerns processor instruction architecture, whereas RAM is the volatile component used for working memory.
Q10: For an everyday spreadsheet, which processor model remains the ordinary choice?
  1. Classical CPU operating on bits ←
  2. Fault-tolerant quantum processor using logical qubits
  3. Analogue neuromorphic processor
  4. Photonic quantum sampler
Quantum machines target specialised problem classes; normal applications continue to run on classical CPUs and conventional memory.
