Practice Questions

Q1: A mobile app offers instant payments, small loans, and digital insurance. Which sector is it in?
  1. Fintech ←
  2. Telemedicine
  3. Streaming media
  4. Civil engineering
Fintech applies software and data to financial activities including payments, lending, investing, and insurance.
Q2: Which activity is telemedicine?
  1. A remote clinical consultation by video ←
  2. Streaming a concert
  3. Buying shoes online
  4. Monitoring soil moisture only
Telemedicine uses telecommunications to deliver clinical healthcare when patient and clinician are in different locations.
Q3: Sensors vary fertiliser application across a field according to soil data. What is this?
  1. Precision agriculture ←
  2. E-commerce
  3. Fintech lending
  4. Media streaming
Precision agriculture combines measurement, positioning, and analysis to apply farm inputs where and when they are needed.
Q4: What distinguishes streaming from a conventional complete download?
  1. Playback can begin while data continues arriving ←
  2. The entire file must arrive before playback starts
  3. Streaming never buffers data on the receiving device
  4. Streaming requires permanent offline storage of the complete file
Streaming delivers successive media data over a network so playback need not wait for the entire file.
Q5: Which transaction is the clearest example of e-commerce?
  1. Ordering a product through an online marketplace ←
  2. Booking a remote clinical consultation
  3. Starting an on-demand film stream
  4. Viewing a city traffic dashboard
Electronic commerce covers buying and selling goods or services through online and other electronic networks.
Q6: Traffic sensors adjust signal timing to reduce congestion. Which concept does this illustrate?
  1. Smart city ←
  2. Precision agriculture
  3. Telemedicine
  4. Fintech
Smart-city systems use connected devices and data analysis to improve urban infrastructure and public services.
Q7: How does fintech commonly support e-commerce?
  1. By processing payments and detecting transaction fraud ←
  2. By providing the product-search and catalogue layer
  3. By operating the parcel warehouse and delivery fleet
  4. By manufacturing the goods offered by each seller
Online trade needs financial rails for authorisation, settlement, credit, and risk management, all common fintech functions.
Q8: A video platform is used for a remote diagnosis. Which term describes the clinical service, not merely the media transport?
  1. Telemedicine ←
  2. Streaming
  3. E-commerce
  4. Smart metering
Streaming carries the call, but the regulated act of delivering healthcare remotely is telemedicine.
Q9: Which pairing captures a shared technology but different setting?
  1. Precision agriculture and smart cities both use sensor data ←
  2. Streaming and telemedicine always describe the same service
  3. Fintech and e-commerce are identical because both accept payments
  4. Smart-city analytics cannot use techniques also used on farms
Farms and cities can both optimise resources with sensing and analytics, though their decisions concern crops and urban systems respectively.
Q10: Which proposal is least consistent with a smart-city project?
  1. Adaptive public transport information
  2. Networked water-leak detection
  3. Data-driven waste collection
  4. Removing all measurement from city services ←
Smart-city programmes depend on useful measurement and connected management; eliminating data collection removes the defining mechanism.
