Practice Questions

Q1: Which description is broad enough to cover reasoning, perception, and language tasks performed by machines?
  1. Artificial intelligence ←
  2. Machine learning
  3. Computer vision
  4. Natural-language processing
Artificial intelligence is the umbrella field; machine learning, language systems, and rule-based reasoning are approaches or applications within it.
Q2: What distinguishes machine learning from a system made only of fixed hand-written rules?
  1. It improves a model using data ←
  2. It must use a physical robot
  3. It stores files in the cloud
  4. It verifies fingerprints by definition
Machine learning estimates patterns from examples or feedback so performance can improve without specifying every decision rule manually.
Q3: A startup rents servers for one week and releases them after a traffic spike. Which model is this?
  1. Colocation hosting
  2. Cloud computing ←
  3. Reserved dedicated hosting
  4. Owned on-premises infrastructure
Elastic, on-demand access to shared servers and storage is a defining cloud-computing capability.
Q4: Which combination is most characteristic of robotics?
  1. Database tables, keys, and queries
  2. Mechanical structures, sensors, and control software ←
  3. Cameras, labels, and a static image archive
  4. Servers, switches, and storage arrays
A robot couples physical mechanisms and actuators with sensing and software so it can act in the real world.
Q5: Which identifier is biometric rather than something a user knows or carries?
  1. Password
  2. Security token
  3. Iris pattern ←
  4. Personal identification number
An iris pattern is a measurable physical trait; passwords are knowledge factors and tokens are possession factors.
Q6: A model produces a new image from a text prompt. Which AI category best fits?
  1. Generative AI ←
  2. Discriminative classification
  3. Rule-based expert system
  4. Robotic process automation
Generative AI learns distributions in training data and creates new text, images, audio, video, or code from prompts.
Q7: Which hierarchy is correct?
  1. Artificial intelligence is only a branch of biometrics
  2. Machine learning is a method within AI ←
  3. Cloud computing is a subfield of robotics
  4. Generative AI contains the entire field of machine learning
Machine learning is one route to artificial intelligence; the two terms overlap but are not interchangeable.
Q8: A spam filter changes after learning from labelled messages. What is doing the learning?
  1. Machine-learning model ←
  2. Static rule list
  3. Message transport agent
  4. Signature-only filter
Learning from labelled examples to classify later messages is supervised machine learning, even if the model runs in the cloud.
Q9: Which statement corrects the claim that every robot is intelligent?
  1. Physical automation can follow fixed control rules without AI ←
  2. Every robot must adapt its behaviour by learning from data
  3. A machine becomes a robot only when it uses generative AI
  4. Remote control alone proves that a robot reasons autonomously
Robotics concerns machines acting physically; some use AI for perception or planning, while others execute predetermined control sequences.
Q10: Why is cloud computing often paired with large generative models?
  1. It supplies scalable processors and storage ←
  2. It guarantees accurate model outputs
  3. It supplies all training data automatically
  4. It removes the need for model optimisation
Cloud platforms make costly accelerators and elastic deployment capacity available without each user owning a data centre.
