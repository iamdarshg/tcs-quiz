Practice Questions

Q1: Which calculating aid works by moving counters along rods or grooves?
  1. Slide rule
  2. Abacus ←
  3. Pascaline
  4. Difference Engine
An abacus represents numbers with movable counters and supports manual arithmetic; it does not execute a stored program.
Q2: Ada Lovelace's celebrated algorithm appeared in notes about which proposed machine?
  1. ENIAC
  2. Analytical Engine ←
  3. Colossus
  4. UNIVAC I
Lovelace annotated Menabrea's account of Babbage's Analytical Engine and described a method for calculating Bernoulli numbers.
Q3: Put these milestones in chronological order: Turing's universal-machine paper, ENIAC completion, transistor invention.
  1. Transistor, ENIAC, Turing paper
  2. ENIAC, Turing paper, transistor
  3. Turing paper, ENIAC, transistor ←
  4. Turing paper, transistor, ENIAC
Turing published the model in 1936, ENIAC was completed in 1945, and Bell Labs demonstrated the transistor in 1947.
Q4: A quiz clue says "general-purpose electronic computer completed in 1945." Which answer fits best?
  1. ENIAC ←
  2. EDSAC
  3. Manchester Baby
  4. UNIVAC I
ENIAC is the expected 1945 general-purpose electronic-computer answer; the Analytical Engine remained unbuilt and the Manchester Baby ran later.
Q5: An engineer replaces a vacuum-tube switch with a smaller solid-state device invented at Bell Labs in 1947. What is it?
  1. Relay
  2. Transistor ←
  3. Vacuum tube
  4. Magnetic-core memory
The Bell Labs transistor could switch and amplify electronically without the bulk and heat of a vacuum tube.
Q6: What quantity did Gordon Moore originally track when formulating the observation called Moore's Law?
  1. CPU clock speed
  2. Semiconductor feature size
  3. Components on an integrated circuit ←
  4. Instructions executed per second
Moore examined component density on integrated circuits; the familiar shorthand later focuses on transistor counts, not clock speed.
Q7: Which comparison between an abacus and ENIAC is accurate?
  1. Both were electronic stored-program computers
  2. Only the abacus used vacuum tubes
  3. The abacus is manually operated; ENIAC used electronic circuits ←
  4. ENIAC predates ancient calculating frames
The abacus depends on human manipulation of counters, whereas ENIAC automated arithmetic with electronic vacuum-tube circuitry.
Q8: Which pairing is correctly matched?
  1. Ada Lovelace — PageRank
  2. Ada Lovelace — Bernoulli-number algorithm ←
  3. Alan Turing — invention of the transistor
  4. Gordon Moore — Analytical Engine designer
Lovelace's notes included an Analytical Engine procedure for Bernoulli numbers, an early published machine algorithm.
Q9: A statement calls Turing the builder of ENIAC. What is the correction?
  1. He designed the Analytical Engine
  2. He proposed a mathematical model of universal computation ←
  3. He co-invented the transistor
  4. He formulated Moore’s Law
Turing's key link here is the universal Turing machine, a theoretical model; Eckert and Mauchly led ENIAC's construction.
Q10: Which development most directly makes Moore's Law meaningful?
  1. Increasing CPU clock speed alone
  2. Increasing transistor density on chips ←
  3. Increasing magnetic-core memory size
  4. Increasing the number of vacuum tubes per machine
The observation describes repeated increases in how densely semiconductor manufacturers integrate transistors, enabling greater computing capability per chip.
